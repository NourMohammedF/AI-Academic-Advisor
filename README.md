# 🤖 المرشد الأكاديمي الذكي - جامعة الإسكندرية

## 📋 نظرة عامة

المرشد الأكاديمي الذكي هو تطبيق متقدم يستخدم تقنيات الذكاء الاصطناعي ونظام RAG (Retrieval-Augmented Generation) لمساعدة طلاب جامعة الإسكندرية - كلية التربية في تحليل نتائجهم الدراسية وتقديم التوصيات الأكاديمية المخصصة.

## 🚀 الميزات الرئيسية

### 🤖 نظام RAG المتقدم
- **تحليل ذكي للوائح الدراسية**: فهم عميق للقواعد والمتطلبات الأكاديمية
- **توصيات مخصصة**: بناءً على البيانات الفعلية للطالب واللائحة الدراسية
- **خطط تحسين ذكية**: خطط مخصصة لرفع المعدل التراكمي
- **تحليل المخاطر**: تحديد المخاطر الأكاديمية مبكراً

### 📊 تحليل النتائج الدراسية
- **رفع ملفات PDF/Word**: استخراج البيانات تلقائياً من ملفات النتائج
- **حساب المعدل التراكمي**: حساب دقيق بناءً على نظام الدرجات الجامعي
- **تحليل الأداء**: تقييم شامل للأداء في المواد المختلفة
- **توصيات اختيار المواد**: إرشادات لاختيار المواد المناسبة

### 🎓 خطط التخرج
- **خطة التخرج التفصيلية**: جدول زمني للتخرج
- **توزيع المواد**: تخطيط ذكي للمواد على الفصول الدراسية
- **تحليل المخاطر**: تحديد العقبات المحتملة
- **التوصيات**: نصائح لضمان التخرج في الوقت المحدد

### 📚 دعم اللوائح الدراسية
- **لائحة شعبة الطفولة**: متكاملة ومحدثة
- **لائحة شعبة التربية الخاصة**: قيد التطوير
- **لائحة شعبة التربية الرياضية**: قيد التطوير
- **قابلية التوسع**: إضافة لوائح جديدة بسهولة

## 🛠️ التقنيات المستخدمة

### Frontend
- **React Native**: تطوير تطبيق الهاتف المحمول
- **TypeScript**: برمجة آمنة وقابلة للصيانة
- **Expo**: إطار عمل سريع للتطوير

### Backend & AI
- **OpenRouter API**: وصول لـ GPT-4o-mini
- **نظام RAG مخصص**: تحليل ذكي للوائح الدراسية
- **PDF.js**: قراءة ملفات PDF
- **Mammoth.js**: قراءة ملفات Word

### البيانات
- **TypeScript Interfaces**: هياكل بيانات منظمة
- **JSON**: تخزين البيانات واللوائح
- **Local Storage**: حفظ البيانات محلياً

## 📱 كيفية الاستخدام


1. **اختر اللائحة الدراسية**: شعبة الطفولة، التربية الخاصة، أو التربية الرياضية
2. **رفع الملف**: PDF أو Word يحتوي على النتائج
